# Brand assets

Use the [media kit](https://liberture.com/media-kit) to preview and download the Liberture identity. The repository holds the original [logo marks](../../public/media-kit/logos/), [wordmarks](../../public/media-kit/wordmarks/) and [horizontal and vertical lockups](../../public/media-kit/lockups/).

Use the [pillar icons](../../public/media-kit/pillars/) with their assigned colors. The [design tokens](../../public/media-kit/liberture-design-tokens.json) describe the palette and typography. The [pattern guide](patterns/topographic-pattern-guide.md) covers the contour backgrounds.
